# PuKnowledge public MCP maintenance

This repository is maintained at https://github.com/pulapulapin/pu-mcp.
Use feature branches based on origin/main; do not merge or release automatically.
Do not import private repository history or cherry-pick private commits wholesale.

MCP owns reusable tools, schemas, permissions, versioning and synthetic tests.
Private projects own manuscripts, outlines, characters, decisions, prompts,
source inventories, user paths, runtime configuration and acceptance screenshots.
Never commit those materials, credentials, databases, backups or copyrighted text.
Use explicit registered projects and project-private datasets. No default novel.

Reuse .ai/project-profile.yaml. Read .ai/current.md before substantial work.
All writes require preview, baseline, fingerprint and idempotency protection.
Candidate planning data never becomes Canon automatically. Structure checks do
not prove factual correctness or literary quality. Test with temporary fixtures.
Run proportional tests; distinguish stdio checks from actual host acceptance.
Inspect the exact staged diff for private content before every public push.

Downloads: check system/environment proxies first. Unknown or >1GB downloads
require explicit user consent; no repeated large retries.
