**Subject:** Re: PuKnowledge on Agensi

Hi Joeri,

Thank you for reaching out. I am interested in listing PuKnowledge on Agensi.

Since your email, I have continued developing and validating the public product.
PuKnowledge 0.4.0 Alpha is now a public release candidate under review. It is a
local-first MCP server for long-running AI projects: it restores versioned task
state across chats and agents, keeps evidence and project boundaries traceable,
and requires preview and explicit authorization before persistent writes.

The public candidate has completed synthetic-project host tests on Cursor, TRAE
and Claude Code CLI for tool discovery, preview/save, fresh-session recovery and
cross-project isolation. The public test suite and Python 3.11/3.14 CI are passing.

I agree with the product shape described in your documentation: PuKnowledge
itself remains an independently installed open-source MCP server, while Agensi
delivers a Skill that tells the agent when and how to use it. No private project
data, user database, credentials or local configuration would be included in the
Skill package.

I plan to start with a free, narrowly scoped listing:

**PuKnowledge Project Continuity Starter** — recover an explicit project's exact
task revision and next step in a new agent session, and save a non-Canon handoff
only through preview and explicit authorization.

This lets us validate installation and real user outcomes before preparing any
paid research or long-form writing workflow pack.
