# Structured knowledge

结构化知识使用四类对象：

- Dataset：资料范围、用途和版本。
- Schema：字段、类型、单位和约束。
- Record：符合结构的实体、规则或调查结果。
- Relation：连接准确版本的记录。

证据引用单独绑定到记录字段或判断。`purpose` 使用 `reference`、`model`、`state`；确认状态独立保存，不能因记录属于 `model` 就自动成为已确认事实。

批量导入流程固定为：解析校验、差异预览、原子提交、导入报告。CSV/JSON 内容带 SHA-256，重复判断使用稳定业务 ID，提交绑定预览指纹、数据集基线和幂等键。结构校验成功只证明格式和引用完整，不证明业务事实正确。
